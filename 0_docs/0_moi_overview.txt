The Measure of Insight Benchmark is a humanities‑grounded evaluation suite for AI‑mediated retrieval and RAG systems in large text archives. It is built on the ECCO‑TCP corpus (2,473 eighteenth‑century volumes) and is designed to test whether systems can support core scholarly practices: semantic retrieval, abductive discovery, exploratory search, and inquiry based on descriptive metadata.

For a small set of carefully chosen queries, the benchmark pools and de‑duplicates top passages from three implemented search engines (volume‑level BM25, a passage‑level exploratory semantic engine, and a vector‑based MiniLM retriever with Rocchio feedback). Domain experts then assign graded relevance (R‑Score) and abductive‑potential (A‑Score) labels to these passages. These judgments underlie system‑level metrics (ranking quality, an Adjusted Granularity Score for “relevance caging,” diversity measures, and exploratory/identity‑constrained tasks) that can be applied to both search engines and citation‑exposing RAG interfaces. This repository contains code, data artifacts, and draft rubrics supporting the benchmark’s development.
